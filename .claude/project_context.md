# Constitution Studio — Project Memory

- **Topic**: Constitutional AI (Anthropic, Bai et al. 2022).
- **Core Loop**:
  1. Generate / Input initial response to potentially harmful prompt.
  2. Critique: Model evaluates response against constitutional principles.
  3. Revision: Model rewrites response to remove harms while preserving helpfulness.
- **Constitutional Presets**:
  - Anthropic Harmlessness & Helpfulness (CAI v2)
  - Universal Declaration of Human Rights (UDHR)
  - Cyber & Threat Defense
  - Academic / WCE Ethical AI Framework
